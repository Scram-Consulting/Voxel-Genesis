  🔍 DIAGNÓSTICO - CAUSA RAÍZ
═══════════════════════════════════════════════════════════════════════════════

  PROBLEMA ENCONTRADO:
  ────────────────────────────────────────────────────────────

    Los componentes X y Z del vector forward estaban invertidos.


  CÓDIGO PROBLEMÁTICO (main.cpp línea ~272):
  ────────────────────────────────────────────────────────────

    Vec3 getForward() const {
        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
        return Vec3(
            cosf(pitchRad) * sinf(yawRad),    // ❌ X sin inversión
            sinf(pitchRad),                    // ✓ Y correcto
            cosf(pitchRad) * -cosf(yawRad)    // ❌ Z con doble negativo
        ).normalize();
    }


  POR QUÉ ESTABA INVERTIDO:
  ────────────────────────────────────────────────────────────

    El sistema de coordenadas del juego usa:
    - X positivo = ESTE (derecha en vista Norte)
    - Z positivo = SUR

    Pero el vector forward calculaba:
    - X sin invertir → apuntaba al lado contrario
    - Z con -cos → apuntaba al lado contrario

  ✅ SOLUCIÓN IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════════════

  CAMBIO EN getForward() (main.cpp línea ~272):
  ────────────────────────────────────────────────────────────

    ANTES:
    ──────
    return Vec3(
        cosf(pitchRad) * sinf(yawRad),     // ❌
        sinf(pitchRad),
        cosf(pitchRad) * -cosf(yawRad)     // ❌

    AHORA:
    ──────
    return Vec3(
        -cosf(pitchRad) * sinf(yawRad),    // ✅ X invertido
        sinf(pitchRad),                     // ✅ Y igual
        cosf(pitchRad) * cosf(yawRad)      // ✅ Z corregido
    ).normalize();


  CAMBIOS ESPECÍFICOS:
  ────────────────────────────────────────────────────────────

    1. Componente X: Añadido signo negativo
       cos * sin  →  -cos * sin

    2. Componente Z: Eliminado doble negativo
       cos * -cos  →  cos * cos


═══════════════════════════════════════════════════════════════════════════════
  📐 MATEMÁTICAS CORREGIDAS
═══════════════════════════════════════════════════════════════════════════════

  VECTOR FORWARD CORRECTO:
  ────────────────────────────────────────────────────────────

    X = -cos(pitch) * sin(yaw)
    Y = sin(pitch)
    Z = cos(pitch) * cos(yaw)


  EJEMPLO 1: Mirar a la DERECHA (yaw = -90°)
  ────────────────────────────────────────────────────────────

    Cálculo:
      yaw = -90° = -π/2 rad
      pitch = 0° = 0 rad

      X = -cos(0) * sin(-π/2) = -1 * (-1) = +1  (ESTE ✓)
      Y = sin(0) = 0
      Z = cos(0) * cos(-π/2) = 1 * 0 = 0

      Vector = (1, 0, 0) → ESTE = DERECHA ✓


  EJEMPLO 2: Mirar a la IZQUIERDA (yaw = +90°)
  ────────────────────────────────────────────────────────────

    Cálculo:
      yaw = +90° = +π/2 rad
      pitch = 0° = 0 rad

      X = -cos(0) * sin(π/2) = -1 * 1 = -1  (OESTE ✓)
      Y = sin(0) = 0
      Z = cos(0) * cos(π/2) = 1 * 0 = 0

      Vector = (-1, 0, 0) → OESTE = IZQUIERDA ✓


  EJEMPLO 3: Mirar al NORTE (yaw = 180°)
  ────────────────────────────────────────────────────────────

    Cálculo:
      yaw = 180° = π rad
      pitch = 0° = 0 rad

      X = -cos(0) * sin(π) = -1 * 0 = 0
      Y = sin(0) = 0
      Z = cos(0) * cos(π) = 1 * (-1) = -1  (NORTE ✓)

      Vector = (0, 0, -1) → NORTE ✓


  EJEMPLO 4: Mirar al SUR (yaw = 0°)
  ────────────────────────────────────────────────────────────

    Cálculo:
      yaw = 0° = 0 rad
      pitch = 0° = 0 rad

      X = -cos(0) * sin(0) = -1 * 0 = 0
      Y = sin(0) = 0
      Z = cos(0) * cos(0) = 1 * 1 = +1  (SUR ✓)

      Vector = (0, 0, 1) → SUR ✓
