  CAMBIO 2: Función getForward() (línea ~272)
  ────────────────────────────────────────────────────────────

    ANTES:
    ──────
    Vec3 getForward() const {
        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
        return Vec3(
            cosf(pitchRad) * sinf(yawRad),
            -sinf(pitchRad),  // ← Negativo
            cosf(pitchRad) * -cosf(yawRad)
        ).normalize();
    }


    AHORA:
    ──────
    Vec3 getForward() const {
        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
        return Vec3(
            cosf(pitchRad) * sinf(yawRad),
            sinf(pitchRad),  // ← POSITIVO (invertido)
            cosf(pitchRad) * -cosf(yawRad)
        ).normalize();
    }

  📊 RESUMEN TÉCNICO
═══════════════════════════════════════════════════════════════════════════════

  SISTEMA DE COORDENADAS:
  ────────────────────────────────────────────────────────────

    OpenGL usa:
    - X: derecha positivo
    - Y: arriba positivo
    - Z: hacia cámara positivo


  ÁNGULOS:
  ────────────────────────────────────────────────────────────

    Pitch:
    - Positivo = cámara mira ARRIBA
    - Negativo = cámara mira ABAJO

    Yaw:
    - Rota horizontalmente


  VECTOR FORWARD:
  ────────────────────────────────────────────────────────────

    X = cos(pitch) * sin(yaw)
    Y = sin(pitch)              ← INVERTIDO (antes era negativo)
    Z = cos(pitch) * -cos(yaw)


  RAYCAST:
  ────────────────────────────────────────────────────────────

    Algoritmo: DDA 3D (Digital Differential Analyzer)
    Origen:    Posición de los ojos (player.position + 1.62)
    Dirección: Vector forward (ahora con Y invertido)
    Alcance:   5 bloques
