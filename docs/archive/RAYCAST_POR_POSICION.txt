  PASO 1: Obtener posición del jugador
  ────────────────────────────────────────────────────────────

    player.position = Vec3(X, Y, Z)

    Ejemplo:
      Si estás en: (100, 65, 200)
      Tus pies están en Y = 65


  PASO 2: Calcular posición de los ojos
  ────────────────────────────────────────────────────────────

    Vec3 getEyePosition() const {
        return position + Vec3(0, EYE_HEIGHT, 0);
    }

    EYE_HEIGHT = 1.62 bloques (altura estándar de Minecraft)

    Ejemplo:
      Pies en:  (100, 65.0, 200)
      Ojos en:  (100, 66.62, 200)  ← Este es el origen del raycast


  PASO 3: Obtener dirección de la mirada
  ────────────────────────────────────────────────────────────

    Vec3 getForward() const {
        float yawRad = yaw * (π / 180);
        float pitchRad = pitch * (π / 180);

        return Vec3(
            cos(pitchRad) * sin(yawRad),    // X
            -sin(pitchRad),                  // Y
            cos(pitchRad) * -cos(yawRad)    // Z
        ).normalize();
    }

    Ejemplo (mirando al Norte horizontal):
      Yaw = 180°, Pitch = 0°
      Dirección = (0.00, 0.00, -1.00)


  PASO 4: Ejecutar raycast
  ────────────────────────────────────────────────────────────

    RaycastResult result = raycastBlock(
        world,
        origin,      ← Posición de los ojos (66.62)
        direction,   ← Vector hacia donde miras
        5.0f         ← Alcance máximo
    );


  PASO 5: Detectar bloque
  ────────────────────────────────────────────────────────────

    El algoritmo DDA 3D recorre el grid desde tu posición:

    1. Inicia en (X=100, Y=66.62, Z=200) ← Tus ojos
    2. Avanza en la dirección (0, 0, -1)  ← Norte
    3. Verifica cada voxel del camino
    4. Al encontrar bloque sólido → devuelve posición
    5. Si llega a 5 bloques → se detiene

        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
