  ✅ CONFIRMACIÓN: EL RAYCAST FUNCIONA EN 360° (TODAS DIRECCIONES)

  El sistema de detección de bloques (raycast) ahora funciona en:

  DIRECCIONES CARDINALES HORIZONTALES (8):
  ────────────────────────────────────────────────────────────

    📍 NORTE           (Yaw ≈ 180°)
    📍 NOR-ESTE        (Yaw ≈ 225°)
    📍 ESTE            (Yaw ≈ 270°)
    📍 SUR-ESTE        (Yaw ≈ 315°)
    📍 SUR             (Yaw ≈ 0° / 360°)
    📍 SUR-OESTE       (Yaw ≈ 45°)
    📍 OESTE           (Yaw ≈ 90°)
    📍 NOR-OESTE       (Yaw ≈ 135°)


  DIRECCIONES VERTICALES (3):
  ────────────────────────────────────────────────────────────

    ⬆️  ARRIBA         (Pitch < -45°)
    ➡️  HORIZONTAL     (Pitch entre -45° y +45°)
    ⬇️  ABAJO          (Pitch > +45°)


  COMBINACIONES POSIBLES:
  ────────────────────────────────────────────────────────────

    Total: 8 direcciones horizontales × 3 verticales = 24 direcciones

    Ejemplos:
    - Norte + Arriba    (miras al techo hacia el norte)
    - Sur-Este + Abajo  (miras al suelo hacia el sur-este)
    - Oeste + Horizontal (miras horizontalmente al oeste)
    - etc.

═══════════════════════════════════════════════════════════════════════════════
  📐 MATEMÁTICAS DEL RAYCAST (Cómo funciona)
═══════════════════════════════════════════════════════════════════════════════

  CÁLCULO DEL VECTOR DE DIRECCIÓN:
  ────────────────────────────────────────────────────────────

    Vec3 getForward() {
        float yawRad = yaw * (π / 180);
        float pitchRad = pitch * (π / 180);

        return Vec3(
            cos(pitchRad) * sin(yawRad),    // X (Este-Oeste)
            -sin(pitchRad),                  // Y (Arriba-Abajo)
            cos(pitchRad) * -cos(yawRad)    // Z (Norte-Sur)
        ).normalize();
    }


  COMPONENTES DEL VECTOR:
  ────────────────────────────────────────────────────────────

    X: Movimiento horizontal Este-Oeste
       - X > 0 → Este
       - X < 0 → Oeste
       - X = 0 → No hay movimiento E-O

    Y: Movimiento vertical
       - Y > 0 → Arriba
       - Y < 0 → Abajo
       - Y = 0 → Horizontal

    Z: Movimiento horizontal Norte-Sur
       - Z > 0 → Sur
       - Z < 0 → Norte
       - Z = 0 → No hay movimiento N-S


  EJEMPLOS DE VECTORES:
  ────────────────────────────────────────────────────────────

    Dirección SUR (Yaw=0, Pitch=0):
      Dir: (0.00, 0.00, 1.00)
      → Solo componente Z positivo

    Dirección NORTE (Yaw=180, Pitch=0):
      Dir: (0.00, 0.00, -1.00)
      → Solo componente Z negativo

    Dirección ESTE (Yaw=270, Pitch=0):
      Dir: (1.00, 0.00, 0.00)
      → Solo componente X positivo

    Dirección ARRIBA (Yaw=0, Pitch=-90):
      Dir: (0.00, 1.00, 0.00)
      → Solo componente Y positivo

    Dirección SUR-ESTE + ABAJO (Yaw=315, Pitch=45):
      Dir: (0.50, -0.71, 0.50)
      → Componentes X, Y, Z mixtos


  ALGORITMO DDA 3D:
  ────────────────────────────────────────────────────────────

    El algoritmo "Digital Differential Analyzer 3D" recorre
    el grid de voxels siguiendo el rayo en la dirección calculada.

    1. Inicia en la posición de la cámara
    2. Avanza por el grid voxel a voxel
    3. En cada voxel verifica si hay un bloque sólido
    4. Si encuentra uno, devuelve su posición
    5. Si llega a 5 bloques de distancia, se detiene

  🎯 BLOQUES DETECTABLES

  SÓLIDOS (SE DETECTAN):
  ────────────────────────────────────────────────────────────

    ✅ BLOCK_DIRT      → Tierra
    ✅ BLOCK_GRASS     → Césped
    ✅ BLOCK_STONE     → Piedra
    ✅ BLOCK_WOOD      → Madera
    ✅ BLOCK_LEAVES    → Hojas
    ✅ BLOCK_SAND      → Arena
    ✅ BLOCK_BEDROCK   → Roca base (detectable pero no rompible)


  NO SÓLIDOS (SE IGNORAN):
  ────────────────────────────────────────────────────────────

    ❌ BLOCK_AIR       → Aire (transparente)
    ❌ BLOCK_WATER     → Agua (líquido)
    ❌ BLOCK_TALLGRASS → Pasto alto (decorativo)


  COMPORTAMIENTO:
  ────────────────────────────────────────────────────────────

    Si apuntas a través de:
    - Aire       → El raycast continúa
    - Agua       → El raycast continúa
    - Pasto alto → El raycast continúa

    Y detecta el primer bloque SÓLIDO detrás de ellos.
