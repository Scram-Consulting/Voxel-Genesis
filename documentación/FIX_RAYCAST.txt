  CAUSA RAÍZ:
  ────────────────────────────────────────────────────────────

    1. Raycast CORTO (1.5 bloques) - Detecta TODO

       → Problema: Detectaba TALLGRASS (pasto alto) cerca del jugador
       → Resultado: Bloqueaba la detección de bloques sólidos

    2. Raycast LARGO (5.0 bloques) - Solo bloques sólidos
       → Solo se ejecutaba si el primero NO encontraba nada


  CÓDIGO PROBLEMÁTICO:
  ────────────────────────────────────────────────────────────

    RaycastResult shortResult = raycastBlockAll(world, origin, direction, 1.5f);
    RaycastResult result = shortResult;

    if (!shortResult.hit) {
        result = raycastBlock(world, origin, direction, 5.0f);
    }

  📊 DETALLES TÉCNICOS
═══════════════════════════════════════════════════════════════════════════════

  ALGORITMO DE RAYCAST:
  ────────────────────────────────────────────────────────────

    Nombre:        DDA 3D (Digital Differential Analyzer)
    Función:       raycastBlock()
    Distancia:     5.0 bloques (alcance estándar Minecraft)
    Detección:     Solo bloques sólidos
    Ignora:        BLOCK_AIR, BLOCK_WATER, BLOCK_TALLGRASS


  BLOQUES DETECTABLES:
  ────────────────────────────────────────────────────────────

    ✓ BLOCK_DIRT      (Tierra)
    ✓ BLOCK_GRASS     (Césped)
    ✓ BLOCK_STONE     (Piedra)
    ✓ BLOCK_WOOD      (Madera)
    ✓ BLOCK_LEAVES    (Hojas)
    ✓ BLOCK_SAND      (Arena)
    ✓ BLOCK_BEDROCK   (Roca base - irrompible pero detectable)

    ✗ BLOCK_AIR       (No se detecta)
    ✗ BLOCK_WATER     (No se detecta)
    ✗ BLOCK_TALLGRASS (No se detecta - decorativo)


  CÁLCULO DEL VECTOR DE DIRECCIÓN:
  ────────────────────────────────────────────────────────────

    Vec3 getForward() const {
        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
        return Vec3(
            cosf(pitchRad) * sinf(yawRad),    // X
            -sinf(pitchRad),                   // Y (vertical)
            cosf(pitchRad) * -cosf(yawRad)    // Z
        ).normalize();
    }

    - yaw:   Rotación horizontal (-180° a +180°)
    - pitch: Rotación vertical (-89° a +89°)
    - El componente Y es el que permite detectar arriba/abajo


  ORIGEN DEL RAYCAST:
  ────────────────────────────────────────────────────────────

    Vec3 getEyePosition() const {
        return position + Vec3(0, EYE_HEIGHT, 0);
    }

    EYE_HEIGHT = 1.62 bloques (altura de los ojos en Minecraft)

  🧪 PRUEBAS SUGERIDAS
═══════════════════════════════════════════════════════════════════════════════

  PRUEBA 1: Romper bloques hacia ABAJO
  ────────────────────────────────────────────────────────────

    1. Posiciónate sobre bloques de piedra
    2. Mira hacia ABAJO (mueve el mouse hacia abajo)
    3. Apunta con la cruz blanca a un bloque del suelo
    4. Mantén CLICK IZQUIERDO

    ✅ RESULTADO ESPERADO:
       - Aparece outline negro en el bloque
       - Aparecen grietas progresivas
       - El bloque se rompe
       - Aparecen partículas


  PRUEBA 2: Romper bloques hacia ARRIBA
  ────────────────────────────────────────────────────────────

    1. Coloca bloques arriba de ti (o busca una cueva)
    2. Mira hacia ARRIBA (mueve el mouse hacia arriba)
    3. Apunta con la cruz blanca a un bloque del techo
    4. Mantén CLICK IZQUIERDO

    ✅ RESULTADO ESPERADO:
       - Aparece outline negro en el bloque
       - Aparecen grietas progresivas
       - El bloque se rompe
       - Aparecen partículas


  PRUEBA 3: Romper en diagonal
  ────────────────────────────────────────────────────────────

    1. Mira en diagonal (45° abajo y a la derecha)
    2. Apunta a un bloque lejano
    3. Mantén CLICK IZQUIERDO

    ✅ RESULTADO ESPERADO:
       - Funciona correctamente hasta 5 bloques de distancia


  PRUEBA 4: Ignorar pasto alto
  ────────────────────────────────────────────────────────────

    1. Camina por un campo con pasto alto
    2. Mira un bloque detrás del pasto alto
    3. El outline debe estar en el bloque sólido, NO en el pasto

    ✅ RESULTADO ESPERADO:
       - El pasto alto es transparente al raycast
       - Detecta el bloque sólido detrás
