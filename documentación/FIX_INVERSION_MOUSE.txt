  🔍 DIAGNÓSTICO - CAUSA RAÍZ
═══════════════════════════════════════════════════════════════════════════════

  PROBLEMA ENCONTRADO:
  ────────────────────────────────────────────────────────────

    El callback del mouse estaba invertido en el eje vertical (pitch).

    Código problemático (main.cpp línea 2484):
    ───────────────────────────────────────────
    g_gameState->player.pitch += (float)yoffset;  // ❌ INCORRECTO


  POR QUÉ ESTABA INVERTIDO:
  ────────────────────────────────────────────────────────────

    Línea 2475: yoffset = lastMouseY - ypos

    Cuando mueves el mouse HACIA ARRIBA:
    1. ypos disminuye (coordenadas de pantalla)
    2. yoffset = lastMouseY - ypos = POSITIVO
    3. pitch += yoffset POSITIVO = pitch AUMENTA
    4. pitch > 0 se interpreta como "ABAJO" ❌
    5. Resultado: Mueves mouse arriba, cámara mira abajo

    Cuando mueves el mouse HACIA ABAJO:
    1. ypos aumenta
    2. yoffset = lastMouseY - ypos = NEGATIVO
    3. pitch += yoffset NEGATIVO = pitch DISMINUYE
    4. pitch < 0 se interpreta como "ARRIBA" ❌
    5. Resultado: Mueves mouse abajo, cámara mira arriba

    ¡TODO AL REVÉS!


═══════════════════════════════════════════════════════════════════════════════
  ✅ SOLUCIÓN IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════════════

  CAMBIO PRINCIPAL: Invertir el signo en pitch
  ────────────────────────────────────────────────────────────

    ANTES:
    ──────
    g_gameState->player.pitch += (float)yoffset;  // ❌


    AHORA:
    ──────
    g_gameState->player.pitch -= (float)yoffset;  // ✅

    Con este cambio:
    - Mouse arriba → yoffset positivo → pitch DISMINUYE → pitch negativo
    - pitch negativo = mirar ARRIBA ✓
    - Mouse abajo → yoffset negativo → pitch AUMENTA → pitch positivo
    - pitch positivo = mirar ABAJO ✓


  CAMBIO SECUNDARIO: Mantener getForward() original
  ────────────────────────────────────────────────────────────

    Vec3 getForward() const {
        float yawRad = yaw * 3.14159f / 180.0f;
        float pitchRad = pitch * 3.14159f / 180.0f;
        return Vec3(
            cosf(pitchRad) * sinf(yawRad),
            -sinf(pitchRad),  // ← Signo negativo CORRECTO
            cosf(pitchRad) * -cosf(yawRad)
        ).normalize();
    }

    Por qué -sinf(pitchRad) es correcto:
    - pitch negativo (arriba) → sin negativo → Y = -sin = POSITIVO
    - Y positivo = arriba en 3D ✓
    - pitch positivo (abajo) → sin positivo → Y = -sin = NEGATIVO
    - Y negativo = abajo en 3D ✓
